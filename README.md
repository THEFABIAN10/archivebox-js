## ❓ Frequently Asked Questions

**Do I need to install Python or anything technical?**
No. Nothing about the setup requires programming knowledge.

**Does this cost money?**
No. archivebox-js is free and open source.

**Where are my saved pages stored?**
On your own computer, in whatever folder you choose. They are not uploaded to a company's servers.

**Can I still open a saved page if the website is gone?**
Yes. That is the entire point. The capture is independent of the original site.

**Will it work on a slow connection?**
Saving works, but big pages with lots of images will take longer to finish. Give it time and let the page fully load first.

**Can I save pages that require a login?**
Pages you can already see in your browser can generally be captured, because the capture happens in your own browser session.

**What if a page looks broken after saving?**
Try capturing again with the page fully scrolled and loaded. Sites that load content only when you interact with them sometimes need a second attempt.

## 🐣 Troubleshooting Basics

- **Nothing happens when you click save** — reload the page once and try again; the browser may have paused the extension.
- **The saved copy is missing images** — scroll the whole page first so all images load, then capture.
- **The capture stops partway** — very large pages can take a while; close other tabs to free up memory and retry.
- **You cannot find your archive** — check your browser's download location, which is usually the "Downloads" folder.
- **Everything looks fine but opens blank** — make sure you are opening the archive file itself rather than a shortcut to the original website.
